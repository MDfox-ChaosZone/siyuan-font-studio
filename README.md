# 思源字体工坊

[English](https://github.com/MDfox-ChaosZone/siyuan-font-studio/blob/main/README.en.md)

## 功能

| 元素 | 字体 | 字号 | 范围 |
| --- | :---: | :---: | --- |
| 界面 | ✅ | ✅ | 菜单、设置、文档树、侧栏等界面 |
| 编辑器 | ✅ | ✅ | 编辑器中的文档内容 |
| 各级标题 | ✅ | ✅ | H1–H6 可分别设置 |
| 代码 | ✅ | ✅ | 行级代码和代码块，可分开设置 |
| 公式 | ✅ | ✅ | 行级公式和公式块，可分开设置 |
| 关系图 | ✅ | ❌ | 关系图和全局关系图 |
| 思维导图 | ✅ | ✅ | 思维导图块 |
| Mermaid | ✅ | 部分 | 部分图表元素使用固定字号 |
| 表情 | ✅ | ❌ | 文档树、编辑器等处的表情 |

- 可选多个字体，缺失的字符由后面的字体补齐。
- 设置可保存为预设方案，支持导入导出，方便切换和多设备使用。

## 额外说明

- 自己使用时推荐使用体积更小的 WOFF2 字体格式以减小内存和存储占用。
  - TTF/OTF 格式可用 [CloudConvert](https://cloudconvert.com/ttf-to-woff2) 或我的 [FontConvert](https://github.com/MDfox-ChaosZone/Font-Converter) 小工具转换
  - 但涉及到分发字体时要使用原字体，以遵守字体协议中可能存在的限制。
