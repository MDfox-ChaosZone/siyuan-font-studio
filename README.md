[English](https://github.com/MDfox-ChaosZone/siyuan-font-studio/blob/main/README.en.md)

字体过家家：

- 轻松自定义思源中的多种字体元素！
- 自由组合并轻松切换你的字体方案！

## 功能

支持修改以下元素的字体和字号：

| 元素 | 字体 | 字号 | 具体范围 |
| --- | :---: | :---: | --- |
| 界面 | ✅ | ✅ | 菜单、设置、文档树、标签栏、侧栏等思源界面 |
| 编辑器 | ✅ | ✅ | 编辑器中文档的普通正文、标题、列表、引述、表格等内容 |
| 各级标题 | ✅ | ✅ | 文档内 H1–H6 可独立设置；未设置时字体继承编辑器字体，字号跟随思源或主题 |
| 代码 | ✅ | ✅ | 行级代码和代码块；两者可分开设置 |
| 公式 | ✅ | ✅ | 行级公式和公式块；两者可分开设置 |
| 关系图 | ✅ | ❌ | 关系图和全局关系图 |
| 思维导图 | ✅ | ✅ | 在“其他字体设置”中独立调整节点字体、字重和字号 |
| Mermaid | ✅ | 部分 | 部分 Mermaid 图表元素使用独立的固定字号，无法统一覆盖 |
| 表情 | ✅ | ❌ | 文档树、编辑器等位置显示的表情 |

- 导入同一字体的 Bold、Italic 等文件后，粗体和斜体会自动使用真实字形，不再由浏览器模拟。
- 可将设置保存为预设方案，轻松切换；支持导入和导出，方便在多设备间使用。
- 支持选择多个字体，作为缺失字符的候补字体。
- 字体按需加载：启动时仅加载当前方案使用的字体，其余字体在预览或选用时加载。

### 字号设置

- 编辑器字体的字号就是思源的编辑器字号：在插件中调整会同步到思源设置；在思源中用快捷键调整编辑器字号后，再次打开插件窗口时当前方案也会同步为新的字号。
- 等宽字体和公式字体使用默认字号时，按思源或主题的默认比例随编辑器字号缩放；手动设置的字号保持固定，点击“恢复默认字号”可重新跟随。
- 开启“分别设置”后，行级代码与代码块、行级公式与公式块的字号各自独立，互不影响。
- 默认字号显示实际计算值，可包含小数；手动调整仍按整数像素设置。将鼠标悬停在“编辑器字体”旁的提示图标上，可查看字号联动说明。

## 额外说明

- 自己使用时,推荐使用体积更小的 WOFF2 字体格式以减小内存占用。TTF/OTF 格式字体可以通过 [CloudConvert](https://cloudconvert.com/ttf-to-woff2) 在线转换，或使用我的项目 [FontConvert](https://github.com/MDfox-ChaosZone/Font-Converter) 转换。
   - 但涉及到分发时,建议使用字体原格式以遵循可能存在的字体协议限制哦.

## 更新记录

- **v1.3.0**：
  - 设置界面的用语与思源保持一致，如“文档字体”改称“编辑器字体”、“行内代码”改称“行级代码”、“Emoji 字体”改称“表情字体”。
  - 导入同一字体的粗体、斜体文件后自动使用真实字形。
  - 编辑器字体的字号改为直接调整思源编辑器字号，修复与思源字号快捷键冲突、开启行号时代码块行高错乱的问题。
  - 适配思源新版的全局字体、Emoji 修正与自定义字体（Docker、移动端）；思源原生字体设置变化后自动刷新。
  - 修复导入方案时提示信息可被注入 HTML 的安全问题；修复 Emoji 字体覆盖思源编辑器字体等问题；同步后无需重载插件即可应用新设置。
  - 移除社区方案投稿与下载，仅保留作者示例方案下载。
- **v1.2.0**：优化字体加载，启动时仅加载当前方案使用的字体，预览随滚动加载；复用字体信息缓存，Emoji 字体仅在使用时加载。
- **v1.1.2**：
  - 等宽默认字号显示实际计算值；调整文档字号时，等宽和公式的默认字号数值即时刷新。
  - 修复“分别设置”时，行级公式的固定字号影响默认公式块的问题。
  - 修复默认字号超出手动调整范围时，滑条数值与显示值不一致的问题；文档字体新增字号联动提示。
- **v1.1.1**：修复使用插件调整文档或标题字体、字号时，思源的自动编号功能与文本间距不同步的问题。
- **v1.1.0**：新增思维导图字体设置。
- **v1.0.0**：
  - 修复公式恢复默认字号后，滑条数值与实际字号不一致的问题；行级公式和公式块分别显示实际计算字号，默认值可包含小数，手动调整仍按整数像素设置。
  - 修复 neo 等主题下设置提示文字难以看清的问题，提示框使用配套的主题背景和文字颜色。
- **v0.1.9**：新增 H1–H6 独立字体、字重和字号设置，支持恢复默认及预设方案导入导出；默认字号显示实际数值，兼容旧方案；更新插件预览图和使用说明。
- **v0.1.8**：新增社区字体方案投稿、审核与在线下载；支持超限方案分包分享和投稿者自主下架；优化下载页布局与分包保存体验。
- **v0.1.7**：完善可变字体支持；修复公式候补字体字重不生效，以及候补字体错误覆盖 KaTeX 数字和运算符的问题；修复下载示例方案时失败的问题。
- **v0.1.6**：增加对字体字重的显示和选择功能，并适配思源 3.8.2 版本。
- **v0.1.5**：新增示例字体方案的按需下载与自动导入功能，并优化预设方案工具栏布局。
- **v0.1.4 及以前**：完成插件基本功能。
